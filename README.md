# Dashboard de Vendas da Xbox
Respondendo perguntas de negócio com Dashboard.

Usei o método de organização "ABCD" que aprendi com o professor Felipão da DIO, que é para
não poluir o dashboard com coisas complexas de mais ou talvez desnecessárias, mantendo
a praticidade, padronização e fácil compreensão.

# O que isso significa?
- A -> Assets - Os recursos: as logos, ícones e paleta de cores.
- B -> Bases - Os documentos com dados a senrem extraída as informações.
- C -> Cálculos - Pasta onde ficam os cálculos que processam os dados ou a maioria deles.
- D -> Dashboard - Painel visual

# E quais perguntas foram feitas e repondidas?
- Qual o faturamento Total de Vendas de Planos Anuais contendo todas as assinaturas agregadas?
- Qual o faturamento Total de Vendas de Planos Anuais separados por Auto Renovação e Não é Auto Renovação?
- Qual o Total de Vendas de Assinaturas do EAPlay?
- Qual p Total de Vendas do Minecraft Season Pass?

# Tem alguma interação com a dashboard?
Sim, tem um filtro visual, com o qual pode ser alterado entre assinaturas Anuais, Mensais e Quarternal;
o que permite tomar decisões mais acertivas quanto as vendas mais detalhadas.
